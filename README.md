# PokeSweat 客户端下载

这里只发布安装包和游戏更新，不包含项目源码、ROM 或可选资源 Mod。

## 下载与启动

1. 打开 [最新版本下载页](https://github.com/1975435449/pokesweat-releases/releases/latest)，下载 `PokeSweat-Windows-x64-<版本>.zip`。
2. 完整解压后双击 `PokeSweat.exe`，无需另外安装 Java。
3. 按游戏提示自行导入所需 ROM；安装包不提供 ROM。
4. 在 [账号注册页](https://pokesweat.qimi.dpdns.org/register) 创建账号。当前内测仍需管理员提供邀请码。
5. 返回游戏登录，再选择或新建角色。

## 更新与修复

启动器在启动游戏前检查更新，通常只下载有变化的文件。更新前关闭所有本包打开的游戏窗口，再重新启动。个人设置和自行导入的 ROM／Mod 文件会保留。

如果文件损坏，关闭游戏后运行包内 `修复游戏.bat`。启动器或 Java 运行环境升级时需要重新下载完整包；旧内测包首次迁移到当前分发版本也需换一次完整包。

下载或更新需要当前网络能够访问 GitHub 及其官方文件下载域。账号问题见 [帮助页](https://pokesweat.qimi.dpdns.org/help)。
